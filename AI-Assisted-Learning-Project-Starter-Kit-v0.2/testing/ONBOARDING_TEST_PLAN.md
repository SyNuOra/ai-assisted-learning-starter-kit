# Starter Kit v0.2 — Onboarding Test Plan

## Goal

Determine whether onboarding understands the learner before topic discovery without becoming unnecessarily long.

## Test A — Known topic

Start a fresh project and say:

> I am ready to start. I want to learn [topic].

Observe whether the Coordinator:
- explores the learner before prescribing a course;
- confirms the practical purpose of the topic;
- avoids unnecessary topic discovery;
- moves to topic-specific calibration only after enough learner context exists.

## Test B — Unknown topic

Start a fresh project and say:

> I am not sure what I should learn.

Observe whether the Coordinator:
- explores the learner first;
- understands background, goals and constraints;
- proposes a small set of plausible areas;
- explains the rationale;
- asks the learner to choose;
- avoids starting detailed curriculum design before topic selection.

## Measures

Record:
- number of learner turns before topic selection;
- whether the learner felt understood;
- whether questions felt necessary;
- whether the process felt like a conversation or questionnaire;
- quality of topic options;
- whether the Coordinator proposed curriculum too early.

## Target

Approximately 3–5 learner interactions before topic selection when topic discovery is required.

This is a target, not a hard limit.
