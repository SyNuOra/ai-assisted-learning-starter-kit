# AI-Assisted Learning Project Starter Kit v0.2

Version 0.2 refines onboarding based on the first real-world test of v0.1.

## Main change

v0.1 moved too quickly from a brief learner introduction into topic discovery and then into detailed topic-specific curriculum design.

v0.2 separates the process into distinct stages:

1. Learner exploration
2. Topic confirmation or discovery
3. Topic-specific calibration
4. Tailored curriculum

The framework remains subject-neutral.

## v0.2 test objective

Determine whether onboarding can understand the learner sufficiently before proposing learning topics, without becoming a long questionnaire.

Target:

- roughly 3–5 learner interactions before topic selection;
- deeper diagnosis only after a topic is selected;
- topic discovery limited to a small set of plausible directions;
- curriculum design begins only after sufficient learner and topic context exists.

## Planned test sequence

Test 1 — onboarding:
- establish who the learner is;
- understand current work/experience;
- understand what they want to improve or accomplish;
- understand important constraints or preferences.

Test 2 — topic:
- learner already knows topic, or;
- learner asks for recommendations.

Test 3 — calibration:
- ask only topic-relevant questions;
- use short self-assessment;
- add a diagnostic activity only when uncertainty justifies it.

Test 4 — curriculum:
- propose explicit learning outcomes;
- propose a tailored curriculum;
- obtain learner acceptance before detailed lab design.
