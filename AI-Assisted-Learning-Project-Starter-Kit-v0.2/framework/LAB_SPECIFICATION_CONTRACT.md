A detailed lab specification is the contract handed to an implementation participant such as Codex.

Each specification should define:
1. Purpose
2. Learning outcomes
3. Existing knowledge / prerequisites
4. Concepts introduced
5. Concepts reinforced
6. Intended implementation
7. Compare and contrast where relevant
8. Challenge
9. Stretch goal
10. Expected implementation evidence
11. Expected learning evidence
12. Acceptance criteria
13. Explicit out-of-scope items
14. Dependencies
15. Suggested learning time

The specification is produced only after sufficient learner context and accepted learning outcomes exist.

Implementation may not silently redefine the learning contract.
