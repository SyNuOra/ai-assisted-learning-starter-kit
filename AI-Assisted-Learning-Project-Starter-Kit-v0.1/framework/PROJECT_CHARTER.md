# AI-Assisted Learning Framework

**Document:** Project Charter
**Document ID:** PROJECT_CHARTER.md
**Version:** 0.1
**Status:** Starter Kit
**Owner:** Curriculum Architect
**Authority:** Starter Kit Baseline

## Purpose

Provide a reusable operating model for adaptive, AI-assisted learning in an individual learner's ChatGPT Project.

## Primary outcome

Build durable, transferable capability rather than merely completing labs.

## Authority

- Curriculum Architect designs and proposes learning outcomes and curriculum architecture.
- Learner / Decision Owner accepts learning outcomes, priorities, and material curriculum decisions.
- Curriculum Manager / Coordinator manages progression, evaluation, adaptation, and scheduling within accepted outcomes.
- Codex implements approved specifications where a Codex project is used.

## Separation

The framework is shared.

Learner-specific curriculum and progression are created inside each learner's project.

The framework does not prescribe the subject.
