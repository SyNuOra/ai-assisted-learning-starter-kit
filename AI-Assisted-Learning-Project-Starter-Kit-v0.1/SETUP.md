# Learning Project Setup v0.1

## Objective

Create a new, individual ChatGPT Project for one learner using this Starter Kit.

## Setup

1. Create a new ChatGPT Project for the learner.
2. Prefer project-only memory when available and appropriate.
3. Paste `PROJECT_INSTRUCTIONS.md` into Project Instructions.
4. Upload all files under `framework/` as Project Sources.
5. Upload `learner/LEARNER_PROFILE_TEMPLATE.md` and `learner/LEARNING_PROJECT_SETUP.md` as Project Sources.
6. Start a new chat in the learner's project.

The learner should be able to begin with an ordinary statement such as:

- "I'm ready to start."
- "I want to improve my REST API skills."
- "I'm not sure what I should learn next."

The learner should not need to explain the framework, choose an internal role, or provide a manual initialization prompt.

## Expected onboarding

The Curriculum Manager / Coordinator should:

1. establish the relevant project context internally;
2. understand the learner's background and practical experience;
3. understand constraints and preferred ways of learning;
4. determine whether the learner already has a topic;
5. if a topic is known, confirm and clarify it;
6. if a topic is not known, briefly review the learner and propose suitable topic areas;
7. let the learner select the desired area;
8. only then move into curriculum architecture.

## Do not start with

- a fixed generic course;
- detailed labs;
- a large questionnaire;
- a Codex project;
- a predetermined technology stack.

## v0.1 acceptance test

Setup is successful when a learner can start a new chat with a normal request and the project correctly handles onboarding without requiring the learner to understand the framework's internal roles.
