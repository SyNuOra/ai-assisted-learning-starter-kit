# AI-Assisted Learning Project Starter Kit v0.1

This package is a reusable starter for creating an individual ChatGPT learning project.

It is derived from the accepted AI-Assisted Learning Framework Operating Model Version 1.0.

## Purpose

A learner creates and owns their own ChatGPT Project. The framework provides the operating model; the learner supplies their background, goals, constraints, and topic preference.

The project then:

1. understands the learner;
2. helps identify or confirm a learning topic;
3. establishes learning outcomes;
4. creates a tailored curriculum;
5. adapts progression using evidence and feedback;
6. coordinates learning activities and scheduling where available.

## Important boundary

This package contains the reusable learning framework, not a fixed curriculum.

Do not copy a learner's personal curriculum, project state, concept ledger, or journal into another learner's project.

## v0.1 test scope

Initial testing covers:

- project setup;
- learner onboarding;
- learner-facing coordination;
- known-topic and unknown-topic paths;
- initial learner profile.

The next test stage covers:

- topic selection;
- tailored curriculum generation;
- acceptance of initial learning outcomes.

A later stage can cover:

- detailed lab specification;
- Codex handoff;
- learning evidence and mini-evaluation.
