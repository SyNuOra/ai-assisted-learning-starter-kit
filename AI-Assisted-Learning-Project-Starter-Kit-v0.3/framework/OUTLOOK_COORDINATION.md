**Owner:** Curriculum Manager / Coordinator
**Authority:** Starter Kit Baseline

If Outlook integration is available, the Curriculum Manager / Coordinator owns learning-activity scheduling.

Responsibilities:
- check availability before creating or moving learning blocks;
- avoid meetings, OOO, vacation, blocked periods, and unavailable time;
- create or update learning events;
- reschedule when learner availability changes.

The curriculum is authoritative. Outlook is its calendar representation.

Scheduling does not determine topic or curriculum.
