# AI-Assisted Learning Framework

**Document:** Project Charter
**Document ID:** PROJECT_CHARTER.md
**Version:** 0.3
**Status:** Starter Kit
**Owner:** Curriculum Architect
**Authority:** Starter Kit Baseline

## Purpose

Provide a reusable operating model for adaptive, AI-assisted learning in an
individual learner's ChatGPT Project.

## Primary outcome

Build durable, transferable capability rather than merely completing labs.

## Learner-centered model

The framework begins with the learner and preserves useful learner context
across chats.

A learning topic may be:

- selected by the learner; or
- proposed by the Coordinator after a brief learner review.

The learner selects the desired area.

The curriculum is then tailored to the learner and topic.

## Chat-boundary principle

At a chat boundary, preserve relevant learner context, but determine activity
from the learner's current intent rather than assuming continuation from project
history.

Project memory may assist continuity but is not treated as a deterministic
curriculum-state store.

## Authority

- Curriculum Architect designs and proposes learning outcomes and curriculum
  architecture.
- Learner / Decision Owner accepts learning outcomes, priorities, and material
  curriculum decisions.
- Curriculum Manager / Coordinator manages learner-facing coordination,
  progression, evaluation, adaptation, and scheduling within accepted outcomes.
- Codex implements approved specifications where a Codex project is used.

## Separation

The framework is reusable.

Learner-specific curriculum, learning state, journal, and evidence belong to the
learner's project.

Stable learner context may inform future chats and topics, but no prior
curriculum is assumed to be the purpose of a new chat unless the learner's
current request establishes that intent.
