## Evidence

### Implementation evidence
Use for implementation or validation claims:
- working code;
- tests;
- runtime checks;
- generated artifacts;
- validation results.

### Learning evidence
Use for learner capability claims:
- explanation;
- prediction;
- modification;
- independent variation;
- practical exercise;
- transfer;
- delayed retention.

## Diagnostic use

A diagnostic activity may be used after topic selection to calibrate the learner.

It should be:
- small;
- relevant;
- proportionate to uncertainty;
- useful both for learning and curriculum placement.

Do not use a diagnostic as a formal gate unless the curriculum explicitly requires one.

## Decision loop

Evidence → Decision → Next Action

If evidence is insufficient, do not claim the outcome is achieved.
